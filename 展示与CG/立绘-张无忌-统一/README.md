# 张无忌立绘 · 四视角统一

源图（`展示与CG/素材/`）：

| 源文件 | 原始尺寸 | 内容 |
|---|---|---|
| `zw_front.png` | 419×591 | 正面 |
| `zw_side3.png`（实为 JPEG） | 1120×1568 | 左侧视图（面朝画面左） |
| `zw_side.png` | 425×594 | 右侧视图（面朝画面右，3/4） |
| `zw_rear.png`（实为 JPEG） | 1088×1568 | 背面 |

四张的**分辨率、画幅比例、取景松紧、背景、色调**都不一致，另外正面/侧面两张还压着
「明教四杰·张无忌」金色标题水印。

统一后的输出（本目录）：

| 文件 | 尺寸 | 说明 |
|---|---|---|
| `zw_front.png` / `.webp` | 576×768 | 正面 |
| `zw_side.png` / `.webp` | 576×768 | 左侧 |
| `zw_sideR.png` / `.webp` | 576×768 | 右侧 |
| `zw_back.png` / `.webp` | 576×768 | 背面 |
| `_统一预览-四视角.png` | 2352×768 | 四联预览（深色底） |

统一规则：

1. **同画布** 576×768（3:4，与展示页牌面 420×560 同比，不再被 `object-fit` 二次裁切）
2. **头顶对齐** 王冠顶统一落在 y=52
3. **同头身比** 按"王冠顶→下巴"高度归一，缩放系数：正面/右侧 1.10、左侧 0.45、背面 0.41
4. **水平对中** 按全身轮廓质心对齐画布中线
5. **背景统一** 抠出人物、去掉水印与地面投影，输出透明底 → 场景背景由展示页统一提供
6. **色调统一** 亮度/饱和度迭代收敛到同一目标（亮度 108），再统一加对比与暗部偏冷

PNG 是透明底母版（可再改）；展示页里内嵌的是 WebP（带 alpha，体积约为 PNG 的 1/7）。

嵌入位置：`精英展示-05-3D旋转全景版v3-GLM5.3.html` 的 `PRELOAD.zw`，
槽位 `front / side / sideR / back`。
