## 规则声明

协作规则分两套，各管一边：

| 谁 | 准则 | 定位 |
|---|---|---|
| **网页端** | `04 网页端协议.md` | **主笔（大脑）**：想、写代码、出「旧→新」对比清单 |
| **本地 Agent** | `12 协议与准则/05 IDE协议.md` | **手**：照清单落盘、不做设计判断 |

分工内核：**网页端 = 大脑；人 = 主要的手；本地 Agent = 备用的手。** 能人做就人做，Agent 只在「人不在电脑前」或「大批量重复操作」时补位。

其余位置只能是**引用 / 指针 / 转发副本**：

- `04 网页端协议.md`（仓根）—— 与 `12 协议与准则/04` 同内容的转发副本，方便查看
- `<工作区根>/.trae/rules/核心工作准则.md`（**仓库外**）—— 冷启动薄壳，TraeCode 每轮自动注入
- `12 协议与准则/09 架构铁律12条.md` —— 技术约束（与 `04` 第六节一致），两边都守
- `12 协议与准则/10 多会话并行协议.md` —— 本地同机并发
- `06 / 07 / 08 协议.md` —— 各专项 agent 协议

优先级：**用户当前指令 ＞ 网页端准则（`04`）＞ 本地 Agent 准则（`05`）＞ 冷启动薄壳 ＞ 专项文档 ＞ 归档 / 履历**。

> 2026-10-20 定位调整：从「IDE 协议族为唯一真源、网页端只是分发副本」改为「网页端主笔 + 本地落盘」双轨。网页端不再是副本，`05` 从 50 条瘦身为 26 条、只留执行类规则。

## 顶层目录

| 目录 | 内容 |
|---|---|
| `core/` | 战斗引擎（回合、伤害、buff、攻击步骤、共享工具） |
| `modules/` | 阵营组件（明教 25-27 精英、六大派、朝廷）、战斗 Store |
| `render/` | 事实渲染与翻译层（fact renderer、网格、格斗渲染） |
| `player/` | 播放器（播放核心、日志、战报、buff UI、事件处理） |
| `infra/` | 基础设施（事件总线、枚举、核心工具、时钟、契约） |
| `ui/` | 界面、按钮、弹窗 |
| `fx/` | 特效、动画、飘字、弹幕 |
| `content/` | 数据内容表（`200game-data.json`） |
| `tools/` | 开发工具（工具箱、自动对局、平衡分析、商店） |
| `tests/` | 体检与回归验证（回放规则、数值契约、变异牙齿、基线、fuzz） |
| `文件汇总20260730/` | 设计文档（协议 / 准则 / 设定 / 记录 / 优化 / 待办 / 资产 / 延伸） |

> 规则：`push` 直接进 main，不开新分支；推两个远端（`gh-ssh` GitHub / `gitee`）。详见 `05 IDE协议.md` 〇·四、五·4。
