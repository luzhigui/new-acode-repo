# 严阵以待机制实验报告

日期：2026-08-02
实验对象：海克斯 Buff「严阵以待」（防战防御 +50%，反弹 50% 伤害差）

---

## 一、实验目的

验证严阵以待的"加防御"与"反伤"两个子系统各自的实际贡献，以及两者是否存在协同效应。同时观察长局（R9+）中各配置的胜率衰减规律，定位反伤的真正价值区间。

## 二、实验设计

- **阵容**：对称阵容（双方配置完全相同）
- **变量控制**：我方 4 回合单边 Buff，敌方先手，对方无 Buff
- **样本量**：3 组 × 50 轮真实引擎对战
- **对照配置**：
  1. 基线（无 Buff）—— 33% 胜率
  2. 完整版（反伤 + 加防御）
  3. 仅加防御（去掉反伤）
  4. 仅反伤（去掉加防御）

## 三、实验数据

| 配置 | 胜率 | 相对基线增益 |
|------|------|------------|
| 基线（无 Buff） | 33% | — |
| 仅反伤 | 52% | +19% |
| 仅加防御 | 76% | +43% |
| 完整版（反伤 + 加防御） | 90% | +57% |

**协同增益计算**：
- 仅反伤 + 仅加防御 = 19% + 43% = 62%（线性叠加预期）
- 完整版实际 = 57%
- 差值 = 57% - 62% = -5%（负值但不含信息量，因为概率不能简单相加）

更合理的拆法——以"仅加防御 76%"为基准：
- 加防御 → 76%
- 再叠加反伤 → 90%
- 反伤在防御基础上的边际增益 = +14%

**结论**：加防御是绝对主力（+43%），反伤单独仅 +19%，两者协同有 +14% 增益。

## 四、长局分析（R9+）

| 配置 | R1-R8 峰值胜率 | R9+ 胜率 | 跌幅 |
|------|---------------|---------|------|
| 仅加防御 | 92% | 25% | -67%（最陡） |
| 完整版 | — | 50% | 靠反伤撑住 |
| 仅反伤 | — | — | 数据未单列，但三组均跌 |

**核心发现**：

1. **R9+ 三组配置胜率全部下跌**——长局对所有配置都不友好，这是结构性问题，不是 Buff 选择问题。
2. **仅加防御跌幅最陡**（92% → 25%）——纯防御在长局中"叠不动"，防战被耗穿后没有反击手段。
3. **完整版靠反伤撑住 50%**——反伤的真正价值不在前期（前期 +19% 贡献有限），而在长局续航。防战站得住的时候，反伤持续对外输出，形成"防御保生存 → 反伤磨对面"的良性循环。
4. **反伤 = 长局保险**：前期贡献有限，但后期是防止崩盘的关键。

## 五、待排查问题

用户判断：长局胜率低大概率是**站位不行**。

后续验证方向：
- 对比不同站位（防战前排居中 vs 偏侧）在 R9+ 的存活率
- 测试"防战 + 远程后排"与"防战 + 飞行后排"在长局中的差异
- 排查长局中防战是否因遮挡失效而被绕后击杀

## 六、机制备注

- 严阵以待首次选择海克斯时不出现，必须等已有 Buff 剩余回合 > 0 后才可刷出（见 `档案-更改履历.md`）
- 小昭姐姐强化版：反弹同时恢复等量生命（进一步强化续航）
- 防御加成仅对友方生效（历史 bug 修复：原先敌方也吃到）
