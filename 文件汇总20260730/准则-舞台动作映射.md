# 舞台动作映射规范（stageAction）

> 定位：引擎输出 factType → 播放器 stageAction → 格子线/特效线/日志线 三线刷新的统一映射协议。
> 引擎与播放器双方共同遵守；factType 增减时同步维护本表。
> 版本: V5.7.3 | 2026-08-22 建立

## 一、stageAction kind 定义

| kind | 职责 | 格子线 | 特效线 | 日志线 |
|---|---|---|---|---|
| `roundStart` | 新回合 | 清行动标记、刷新待命 | 可选横幅 | 回合开始分隔 |
| `roundEnd` | 回合结束 | 恢复休息、结算buf | 无 | 回合结束分隔 |
| `attack` | 一次普通攻击 | 目标掉血、致死则死亡标记 | 冲撞/箭矢、伤害飘字 | 攻击+伤害行 |
| `miss` | 未命中 | 无 | miss 特效 | 未命中行 |
| `dodge` | 闪避反击 | 双方血条 | 闪避子弹时间、反击飘字 | 闪避行 |
| `immune` | 免疫伤害 | 无 | 可选免疫特效 | 免疫行 |
| `heal` | 治疗 | 血条上涨 | 绿飘字 | 回血行 |
| `statChange` | 属性变化 | 攻防面板/徽章 | 加攻防飘字 | 属性变化行 |
| `posSwap` | 换位 | 格子位置互换动画 | 换位特效 | 换位行 |
| `push` | 击退 | 格子位移动画 | 击退特效 | 击退行 |
| `summon` | 召唤拒马 | 新增格子 | 生成动画 | 召唤行 |
| `destroy` | 销毁拒马 | 移除格子 | 消散动画 | 销毁行 |
| `death` | 死亡结算 | 死亡标记、移除 | 红闪 | 击杀行 |
| `dot` | 持续伤害 | 血条下降 | 中毒特效 | 寒毒行 |
| `execute` | 斩杀 | 死亡标记 | 斩杀特效 | 斩杀行 |
| `transform` | 变身/切形态 | 更新职业图标 | 变身特效 | 变身行+台词 |
| `flyMode` | 飞天/附身/返回 | 格子虚影/归位 | 蝴蝶/蜘蛛动画 | 状态行 |
| `stun` | 眩晕 | 眩晕标记 | 眩晕特效 | 眩晕行 |
| `rest` | 休息 | 回复、休息标记 | 可选 | 休息行 |
| `buffSummary` | buff生效摘要 | 徽章 | 横幅 | 摘要行 |
| `banner` | 纯横幅事件 | 可选徽章 | 大横幅 | 可无日志 |
| `separator` | 分组标记 | 无 | 无 | 分隔线 |

## 三、三线节奏原则

**格子线优先级最高、特效线跟随动作、日志线最慢。**

- 每一步拿到 stageAction，先刷格子（同步、无等待），再触发特效（异步、可叠加），最后按需播日志（可跳过、可延迟）。
- 日志永远不阻塞格子和特效，只阻塞自己的下一句。
- 同一条 stageAction 的"伤害掉血"和"伤害飘字"必须同步触发，但日志文字可以放在飘字前或后，不影响正确性。
