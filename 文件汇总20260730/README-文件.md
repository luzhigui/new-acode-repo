# 光明顶 5v5 协作协议 · 文件管家版

版本: V1.1.0 | 适用: 文件管理专项 agent（TraeCode IDE）

本文档是文件管理专项 agent 的专用协议。你的职责是**管理项目里的 MD 文档**，不修改任何业务逻辑代码。

---

## 一、职责范围（MD 文档管理）

你只负责以下 MD 文档，其余代码一律不碰：

1. **根目录 MD 文档**：
   - `README.md`（网页端协作协议）
   - `记录-更改履历.md`
   - `待办-bug待修.md`
   - 根目录下的其他 `.md` 文件
2. **`文件汇总20260730/` 目录下所有 MD 文档**：
   - 设定类（职业/游戏/人物/流程）
   - 准则类（开发准则/架构决策）
   - 记录类（错误与经验库）
   - 游戏类（玩家指南/杂谈进阶）
   - 优化类（想法和优化）
   - 待办类（事项待办）

## 二、强制规则

1. **只碰 MD 文档**：不修改 `core/`、`player/`、`ui/`、`fx/`、`modules/`、`tools/`、`tests/` 下的任何代码文件。
2. **MD 存放位置**：
   - 项目协议、履历、待办类 MD → 放**根目录**
   - 设定、准则、记录、实验、优化等文档 → 放 `文件汇总20260730/`
   - 不自建新文件夹
3. **不删业务代码**：清理时只删 MD 相关的临时文件，绝不删 `.js`/`.html`/`.cjs`/`.json` 业务文件。
4. **文件名规范**：文件名不带空格；新增 MD 用中文语义命名，不撞号。

## 三、工作方式

1. 用 Glob/Read 定位 MD 文档 → 用 Edit/Write 精确改。
2. 改动后检查：内容完整、格式统一（Markdown 语法、标题层级）。
3. 汇报时给出：改动文件清单 + 改动要点。
