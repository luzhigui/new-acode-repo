## 光明顶 5v5 游戏 —— 创意与设计方案汇总

### 一、核心战斗机制深化

基于现有 M 值拆分、防战 K 值表、遮挡系统，提出以下深化方向：

1.  **韦一笑 “血魔流” 体系**
    -   新 Buff 「寒冰绵掌」：韦一笑攻击时，若目标血量百分比高于自身，附加 `差值 × 0.5` 的伤害。
    -   玩法：刻意控血换取高爆发，再靠吸血回复，形成刀尖跳舞的风格。搭配 “你就是 carry” Buff 能在残局成为强力翻盘点。
    -   （2026-10-04 整理：命名过时——该体系相关技能已实装并改名「蝠影汲血」（去寒冰化）；实装数值以 `content/200game-data.json` 为准。）

2.  **宋青书/周芷若博弈深化**
    -   新 Buff 「攻心为上」：我方女性角色在场时，宋青书的 “性奋” 额外攻击有 40% 概率目标改为周芷若。
    -   联动：周芷若被宋青书攻击 3 次后，会对他释放一次无法闪避的九阴白骨爪。

3.  **拒马战略化**
    -   新 Buff 「拒马枪阵」：拒马阵亡时，对摧毁者造成 `10 + 攻击者 atk × 0.3` 的真实伤害，让破阵付出代价。

### 二、新角色与叙事机制

1.  **殷天正（白眉鹰王）** —— 战士
    -   「鹰爪擒拿」：25% 概率将目标抓至身前空位，此次攻击必中且无视 50% 防御。
    -   「父子连心」：张无忌血量低于 30% 时，殷天正获得一回合狂暴（攻击 +20%，防御 -10%），并移动到张无忌同列前排挡刀，触发特殊叙事台词。

2.  **黛绮丝（紫衫龙王）** —— 飞行（近战位）
    -   「金花打穴」：攻击不造成直接伤害，改为叠加 “金花” 印记。
    -   「龙王真身」：任意单位阵亡时，对场上所有带印记敌人造成 `印记层数 × atk × 0.5` 真实伤害，随后变身为防战形态并获得护盾。一个前期隐忍、中期爆发的战术支点。

3.  **战场事件系统**
    -   **光明顶圣火**：第 5 回合开始，若明教存活少于 3 人，全体获得一次 “免死金牌”（致死伤害保留 1 血），持续 2 回合。

4.  **周书书**（2026-10-15 记，**未落地**）—— 宋青书 与 宋远桥 之女，拟作为**第 4 关常驻角色**（替换宋方一名队友，替换哪位待议）
    -   站位 **M20**；**攻击力 0**；**防御取决于「周芷若上一轮白骨爪的伤害」**（口径待定：单次/该轮合计、是否含连锁多爪）。

### 四、Roguelike 装备对战（1v1 新模式）

独立于 5v5 的全新模式，核心循环：“投资→掉落→合成→战斗”。

-   **投资机制**：初始 100 分，免费 2 次。后续消耗按 `1,2,2,3,3,3,4...` 递增，每次从 9 个词条中随机掉落白装到九宫格。
-   **合成体系**：3 件同名白装自动合成蓝装，并返还 `上次付费价格 × 已合成数量` 的分数。合成后该类型锁定，场上同类其他词条变为死格。
-   **死格与锤子**：合成获得锤子次数，可双击清除死格。未用完的锤子战斗后返还分数。
-   **战斗**：1v1 回合制，步进模式。胜利返还 `投资分数 × (1.5 + 己方蓝装数 × 0.2)`。
-   **选秀**：若干回合后开启，旋转轮盘争夺对方道具。
-   **架构**：敌我状态完全分离，合成检测与执行分离。待定：锤子规则、循环上限、选秀触发回合。

**补充建议**：
-   设定合成返还分数的最低保底（如 5 分），避免前期反馈过弱。
-   明确暴击掉 2 件与天降 +5 分的优先级（先加分，再算掉落）。
-   步进模式中输出详细状态日志。
-   选秀首次触发设于第 5 轮投资后，之后每 3 轮一次。

### 八、圣火令与局外养成系统

> 本系统是**唯一完整方案源**（02 事项待办.md 已收敛为行动清单）。**2026-10-10 定稿**。

**8.1 货币**
-   **圣火令 = 唯一商店货币**，双用途：战斗消耗（每关限 1 次、二选一：恢复我方单角色 30% 最大生命 / 对敌单体造成 15% 最大生命真实伤害）或商店消费。
-   **获取**：积分兑换（50 积分 → 1 令，积分来自"猜胜负"）、战斗掉落（击杀精英 25%、首次通关必掉、有保底）。

**8.2 商品与定价**（价格按**账号累计**计算）

| 商品 | 价格 |
| --- | --- |
| 解锁角色 | 第 1 个 20 令，后续 50 令 |
| 属性点（攻 / 防 / 血） | 第 1 个 50 令，后续 100 令 |
| 经验 | 不出售，宝箱专属 |

-   技能书、装备暂缓（需往战斗内注入技能 / 装备槽，与"明教不搬表"定案冲突），契约里先留空位占坑。
-   养成角色永久保留。

**8.3 等级与经验曲线**
-   **M 值多少就是多少级**，不做二次换算；**等级 = 总 M = `baseM` + 属性点点数三项之和**。
-   `baseM` = 初始 M（如小昭·妹 107、默认战士）+ 经验包升上去的级。
-   升级所需经验 `R(n) = E(n) ± W(n)`，下限 5；`E(n) = 10 + 5n`（线性 +5/级，保证期望单调上升）；半宽 `W` 按「窄—宽」交替 `5, 15, 5, 15…`（各 ±2 抖动），使区间在上升中左右摆动 = 螺旋。
-   区间表：1→2 `10-20`｜2→3 `5-35`｜3→4 `20-30`｜4→5 `15-45`｜5→6 `30-40`｜6→7 `25-55`｜7→8 `40-50`｜8→9 `35-65`｜9→10 `50-60`。

**8.4 属性点与自由点**
-   **每个属性点自带一级经验** → 总 M +1 → 等级 +1。
-   购买的属性点 / 宝箱掉的属性点：+1 个**固定类型点**（攻 / 防 / 血，类型均分），**不给自由点**。
-   宝箱掉的**经验**升 1 级时：**给 1 个自由属性点**（玩家自选攻 / 防 / 血）。
-   自由点进背包，由玩家**自行分配**（可囤、可收藏，不强制使用）。
-   **防循环原理**：属性点自带经验确实推高等级，但属性点产生的这一级**不再产生新的自由点**，只有宝箱经验才产点 → 不会自激。

**8.5 战斗生成**
-   引擎按 **`baseM`** 走标准拆分（hp 基数 / atk / def + 职业修正）。
-   再把 `points` 明细**单独叠加**（走 `addMod` → `getStat`，禁直改属性）。
-   总 M 仅用于展示。

**8.6 数据契约**（localStorage，key = `ming_cultivated_heroes`）

```json
{
  "v": 1,
  "list": [
    { "name": "小昭·妹", "baseM": 107, "role": "战士",
      "points": { "atk": 3, "def": 1, "hp": 2 },
      "skills": [], "equips": [] }
  ]
}
```

-   只有商店页**写**、游戏本体**只读**；字段只增不删、不改名；`list` 内存在即已解锁。
-   `skills` / `equips` 留空数组占位，**暂不参与战斗**。

**8.7 掉落**
-   **宝箱**：通关掉落，第 1 关 3% → 第 7 关 9% 线性递增，首次通关 +5%。
-   **箱内**：属性点 40% / 经验 40% / 圣火令 20%；经验单次给 `8-15`。

**8.8 每日折扣**
-   用日期串 `YYYY-MM-DD` 做种子（纯 hash、零存储、确定性）→ 每天随机挑 1-2 个可购项打折，档位 5/6/7/8/9 折。
-   同一天刷新结果不变，跨天自动换。

**8.9 上场规则与边界**
-   布阵时用养成角色**替换一名常规队友**。
-   技能 / 装备暂无，碰撞职业与技能仍走原组件（不与"明教不搬表"冲突）。
-   商店页属 `tools/` 可直接改；布阵接入属主代码 `ui/`，需用户明确下令或转 DeepSeek 网页端。

### 附录：玄冥二老联动体系梳理（2026-09-19）
