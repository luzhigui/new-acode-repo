## 二、已砍（6 个，带原因）

- **薪火相传** —— 库库回血、没机制（复用张三丰生生不息也救不回"纯回血"）。
- **瘴气缠身** —— 中规中矩（复用玄冥中毒 DoT，团队版没新意）。
- **融汇精通** —— 太窄，`|atk−def|×50%` 只对高防坦（张三丰/胖远桥）有效；想扩得动融汇本身（确凿克制，风险大）。
- **闪避反刺** —— = 已有的"闪避克普攻"（`DODGE_REBOUND_RATIO=0.5`+眩晕），纯换名重复。
- **阴阳手** —— 单烧四邻是空的（玩家躲开就行，没有站边上的理由）；除非配"强制贴脸"或与铁锁连环做"集群 vs 散开"对冲，否则撤。
- **拒马指挥官** —— 敌方往己方九宫格塞拒马，又怪又傻；拒马是巨马阵的己方阵型工具，不该敌方产。

## 三、活口 1：铁锁连环（海克斯，可落地）

- **机制**：任意单位四邻格（上下左右）有存活友军 → 受击减伤 X%。
- **复用**：`qianKunZone` + `applyDamageModifiers`（`modules/20elite-skills.js`）。
- **为什么是真空位**：代码里"四邻保护"只有两个来源——张无忌 `qianKun`（要求 isZhang + rangedForm）和小昭·姊 `qianKunDerived`（张无忌不在时的弱化版），**团队海克斯版没有**。把触发者从具体英雄改成海克斯 = 填这个空。
- **出厂三档（硬规则，不许问）**：
  - 普通：四邻有友军 → 减伤 X%；
  - 姊增强：小昭·姊存活 + buff 生效 → 按 `hexEnhance.tieSuo` 强化（减伤↑/范围↑）；
  - 妹永久：选过进 `_permanentBuffs`，团队 buff 过期后妹单独续弱化版（`XIAO_ZHAO_PERMANENT_BUFFS`）。
- **接入点**：content 加 BUFF；`core/14buff-effects.js` 写 `applyTieSuo_Normal/_Sister/_Brother`；`hexEnhance` 加 `tieSuo` 项；消费接已注册的 `damageModifiers` 查询（`registerQuery('damageModifiers', …)`）。

## 四、活口 2：空见神僧 · 反谢逊（新角色）

- **定位**：少林（六大派之一）。现有精英表（`registerElite` + 建队表 `eliteConfigs`）里没有空见；设定上他就是接谢逊七伤拳、谢逊的心魔，天然克狮王。
- **为什么必须新造**：灭绝师太已满配（反击/追击/峨眉掌法/三击吸血/召唤周芷若，还带 `165-miejue-redesign` 体检规则），不能动。
- **反雪球思路**：谢逊 = 召幼狮 → 成长 → 雄狮振奋（全队攻越打越高）→ 滚雪球。克制 = ①硬减伤扛 grow 起来的高攻 + ②控住雪球 unit 断它击杀。
- **技能草案（全复用现有原语）**：
  1. **金刚不坏体**：受击硬减伤（吃 grow 起来的高攻，减伤比堆防更能扛滚雪球）——复用 `DMG_REDUCTION` 声明，参照小昭 `qianKunDerived`；
  2. **龙爪手擒拿**：命中概率定身/禁疗（锁住雪球 unit，不让它继续击杀涨振奋）——复用杨逍点穴 `_stunned` + `_jinMai` + cd 那套；
  3. （可选）**不还手**：受击减伤 + 反弹——复用严阵以待 rebound（`core/12`）。
- **待定**：具体数值、第三技能要不要、立绘/3D 资产（新角色 = 新模块 `createKongJianComponent` + 新资产）。
- **骨架**：克隆张三丰 `createXxxComponent` + `eventBus.on(SIGNAL,优先级,cb)` + `getSkillParams` + `log.push(fact)`。
