## 二、活口 1：铁锁连环（海克斯，可落地）

- **机制**：四邻格（上下左右）有存活友军 → 受击减伤 X%。
- **复用**：`qianKunZone` + `applyDamageModifiers`（`modules/302-elite-skills.js`）。
- **为什么是真空位**：“四邻保护”在代码里只有张无忌 `qianKun` 和小昭·姊 `qianKunDerived` 两处技能来源，**团队海克斯版没有**；把触发者从英雄换成海克斯 = 填这个空。
- **出厂三档（硬规则，不许问）**：
  - 普通：四邻有友军 → 减伤 X%；
  - 姊增强：小昭·姊存活 + buff 生效 → 按 `hexEnhance.tieSuo` 强化（减伤↑ / 范围↑）；
  - 妹永久：选过进 `_permanentBuffs`，团队 buff 过期后妹单独续弱化版（`XIAO_ZHAO_PERMANENT_BUFFS`）。
- **接入点**：content 加 BUFF；`core/215-buff-effects.js` 写 `applyTieSuo_Normal/_Sister/_Brother`；`hexEnhance` 加 `tieSuo` 项；消费接已注册的 `damageModifiers` 查询。

## 三、活口 2：空见神僧 · 反谢逊（新角色）

- **定位**：少林（六大派之一）。现有精英表里没有空见；设定上他是谢逊心魔，天然克狮王。
- **为什么必须新造**：灭绝师太已满配（反击 / 追击 / 三击吸血 / 召唤周芷若，还带 `165-miejue-redesign` 体检规则），不能动。
- **反雪球思路**：谢逊 = 召幼狮 → 成长 → 雄狮振奋（全队攻越打越高）。克制 = ①硬减伤扛高攻 + ②控住雪球 unit 断击杀。
- **技能草案（全复用原语）**：
  1. **金刚不坏体**：受击硬减伤——复用 `DMG_REDUCTION` 声明，参照小昭 `qianKunDerived`；
  2. **龙爪手擒拿**：命中概率定身 / 禁疗（锁住雪球 unit、断击杀链）——复用杨逍点穴 `_stunned` + `_jinMai` + cd 那套；
  3. （可选）**不还手**：受击减伤 + 反弹——复用严阵以待 rebound（`core/12`）。
- **待定**：具体数值、第三技能要不要、立绘 / 3D 资产（新角色 = 新模块 + 新资产）。
- **骨架**：克隆张三丰 `createXxxComponent` + `eventBus.on(SIGNAL,优先级,cb)` + `getSkillParams`。
