## 二、协作/交互术语

| 术语         | 定义                                                                          | 出处               |
| ---------- | --------------------------------------------------------------------------- | ---------------- |
| 复制包        | 用户提供项目代码的主要方式，通常分多批发送                                                       | README 二         |
| 单独文件       | 用户单独发某个文件，视为覆盖复制包同路径旧内容                                                     | README 二         |
| 逐字提取       | 旧代码必须从用户最新原文逐字节复制，禁止凭记忆                                                     | README 〇·五       |
| 发前自搜       | 发旧代码前先搜匹配次数，多处则加长上下文唯一定位                                                    | README 〇·五       |
| 一组一旧一新     | 一处改动 = 一组旧→新对比；每次 2-4 组，默认 3 组                                              | README 〇·五       |
| 完整文件替换     | 改动量太大时先按完整文件计：完整文件算 1 个交付单位，内部不再按前后对比计组；之后抛开此文件，其余改动继续按前后对比计组               | README 四·4       |
| 改动工作量      | 以「组」为计量单位：一处改动 = 一组一旧一新（默认 3 组）；某文件改动量过大 → 直接发完整文件（算 1 个单位，内部不计对比），其余文件仍按组计。**描述改动量一律量化**：完整文件数 + 前后对比组数（如"1 完整文件 + 2 组对比"），禁止用"大/中/小""少量/大量"等模糊词 | README 四·4 + 〇·五 |
| 改动幅度授权     | 允许推倒重写、中间态可不可运行、留 bug 可接受                                                   | README 〇·〇       |
| 兜底方案       | 未找根因直接绕过的做法，明确禁止                                                            | README 〇·一       |
| 控制台诊断脚本    | 贴 F12 控制台运行的临时脚本，不污染源文件                                                     | README 三         |
| 每轮报告完成度    | 每轮结束对照蓝图给百分比 + 剩余项                                                          | README 三·4       |
| 提示词转 Agent | 协助模式格式：标题/验收N问/背景/步骤/边界/核实                                                  | README 五         |
| 普通模式       | 默认协作模式，详细讨论对齐后再发代码                                                          | README 协作模式总览    |
| 执行模式       | 用户说"发/继续/直接改"时，不讨论直接发改动                                                     | README 协作模式总览    |
| 专题模式       | 复杂架构/顽固 Bug 时全链路分析 + 控制台诊断 + 多方讨论                                           | README 协作模式总览    |
| 协助模式       | 用户声明，代码转给另一 AI/Agent 执行                                                     | README 协作模式总览    |
| 发前自检       | 发改动前必过 6 条自检（逐字/自搜/独立展示/等）                                                  | README 四·0       |
| 版本号/VER    | 发完整文件时必须同步更新头部版本号与 export const VER                                         | README 四·4       |
| 新旧并存       | 改一半留旧路、新旧同时存在，视为返工                                                          | README 〇·六       |
