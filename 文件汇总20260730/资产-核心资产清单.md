### 特效规范：远程命中颤动（2026-09-03 定稿）

**定位**：只有远程飞箭命中，被攻击的格子才颤动；近战（飞撞/白骨爪/溅射爪/斩杀）一律不加。

**触发**（仅 `fx/81fx-arrows-5v5-test.js`）：

- 主箭命中：`markGridShake(unitD.uid, 350)`

- 溅射箭命中：`markGridShake(st.uid, 300)`

**实现**（`render/32-grid-render.js`）：渲染层维护 `_shakeUntil`（uid→到期时间戳）；`renderGrid` 每次重建格子时若未到期，对**新格子**播放 `runGridShake` rAF 颤动并续期。

**视觉**：逐帧随机偏移 ±2px（decay 线性衰减）+ `translate+scale` 0.88→1.0 缩放回弹（300\~350ms）+ 短暂黄闪（≤200ms，金黄色 #ffd700）；结束后还原原 transform/background。

**关键坑（防再犯）**：

1. **不要直接改格子 DOM 颤动**——store 任意一次 dispatch 都会触发 `renderGrid` 用 `innerHTML=''` 整体重建，直接改 cell.style 会被下一帧 rebuild 掐掉。必须走渲染层 `markGridShake` + 重建续期。
2. **不要用 CSS** **`.shake`** **class（±5px 横移）**——远古做法，观感差，已被否定。
3. **不要做 overlay 浮层**（半透明黄块）——观感与格子本体颤动完全不同，已被否定。
4. **粒子函数删干净**：`applyImpactShrink`/`applyImpactShrinkOverlay` 已从 `fx/80fx-common` 删除，全库无残余调用；82 无 markGridShake import。
5. 命中颤动是全屏幕持续战斗内容，**暂停（isPaused）时动画应冻结**——当前 runGridShake 用 Date.now()，若需暂停冻结需改用 rAF 累计模式。

### 特效规范：血条渐变（`render/32-grid-render.js`，2026-09-07 复核）

**机制（亮点：DOM 重建不打断）**：双 Map 持久记录——`_hpTargetPct`（目标值，renderGrid 时写入真实 hpPct）+ `_hpDisplayPct`（显示值，跨重建保留）。显示值不在 DOM 上，所以 `innerHTML=''` 整格重建不会打断渐变。

**动画循环 `tickHpAnim`（每帧 rAF 指数逼近）**：

- `step = |diff| < 2 ? diff : diff * 0.15`——远时按 15% 比例逼近（先快后慢），近时（<2%）直接到位；`|diff| < 0.1` 视为到位
- 每帧 `bar.style.height = next + '%'`；有任一血条未到位则 rAF 续跑
- **快进（fastForwardActive）时直接同步到位**，跳过动画

**颜色三档（按剩余血量百分比，非连续渐变）**：

- `> 70%`：绿 `#4caf50`；`> 40%`：橙 `#ff9800`；`≤ 40%`：红 `#f44336`
- 血字同档：hp-text-green / hp-text-orange / hp-text-red
- **加成血量**（hpBonus/蝴蝶加成/上限提升）血字金色 `#daa520` 加粗

**防误改红线**：

1. 血条渐变走 JS 双 Map + rAF，**不要改成 CSS transition**——DOM 重建会掐断 transition（同受击颤动坑）。
2. 显示值必须存 Map，**不要读回 DOM**（重建后 DOM 是最新值，会跳变）。
3. 颜色分段是产品调性，改阈值/色值前先确认。

## 判据清单（机器核对用，2026-09-16 首版）

> 上文表格给人读；本表给脚本读。把每条"为什么好"落成**可机械核对的锚点**——改到就跑一次，**只在漂移时开口**，不漂不叫。
> 存在意义：靠人记的提醒不可扩展（资产一多必然没人读），把提醒交回机器才守得住。

**四类判据**（脚本只认这四种，不得自创）：

| 类型   | 语义                        |
| ---- | ------------------------- |
| 存在   | 目标列出的**每个**文件都必须含该锚点      |
| 禁现   | 目标范围内**不得**出现该锚点         |
| 计数   | 该锚点全仓出现次数 = N             |
| 人工   | 脚本跳过，归入"待人工复核"提示（品味类资产）   |

**多锚点**：用 `+` 连接，表示全部需命中。

**铁律**：

1. 锚点必须是**符号名/关键字**，**禁止用整文件 hash**——hash 一动就全报，噪音淹没信号，等于没做。
2. 锚点按**调用形态**写（如 `markGridShake(` 带左括号），避免把 import / 注释算成违规。

## 核对脚本规格（交代码侧）

- **输入**：本文件「判据清单」表 + 仓库根
- **动作**：逐行按四类判据核对，输出三态 `命中 / 漂移 / 缺失`
- **输出**：只列非命中项；每项附溯源 `git log -1 --format=%h %ad -S"锚点"`，便于一眼看 diff、直接改回去
- **退出码**：有漂移 → 非 0（便于挂进体检 / 提交前钩子）
- **位置建议**：与现有 `123static-scan.js` 同族（静态扫描），不另开工具链入口
- **节奏**：挂进收尾流程自动跑；独立工具必然被遗忘

## 备注
