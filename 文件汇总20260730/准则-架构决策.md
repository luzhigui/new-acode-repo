# 关键设计决策速查

> 定位：本文档速查"为什么这么设计"的关键决策，每条 1-3 行。
> 详细复盘见 `记录-错误与经验库.md`（四、技术决策档案）；版本变更见 `记录-更改履历.md`。
> 最后更新：V5.3.2 — 事件总线迁移完成（新增 onRoundStart / onRoundEnd / beforeFirstAllyAttack）

## 行动裁判（V5.3.1 / V5.3.2）
*   **beforeActionSelect**：引擎选人前发射信号，单位声明 `priority`（谁先动）、`skip`（不在战场，不进候选池）、`pass`（存在但无法攻击，行动后不换阵营）。裁判统一排序，高优先级抢动，skip 不进候选，pass 行动后不换阵营。
*   **isPriorityAction**：高优先级行动（如苦练）或被遮挡/眩晕等单位完成动作后，设此标记为 true，跳过 `currentSide` 切换，不占本队正常回合。
*   **onRoundStart**：回合开始阶段发射，用于精英组件处理苦练 buff、性奋授予、快乐回血、蛛变、玄冥中毒、永久 carry 等逻辑。⚠️ 必须同步执行，引擎后续属性计算依赖这些加成。
*   **onRoundEnd**：回合结束或战斗结束时发射，用于姐姐蝶变飞回、张无忌变身检查、妹妹蛛落等清理逻辑。
*   **beforeFirstAllyAttack**：明教首次攻击前发射，小昭姐组件监听此信号自行处理蝶变附身，替代引擎硬编码调用。
*   **眩晕双拦截**：`processUnitAttack` 入口拦截（眩晕单位拒收任何攻击指令）+ 攻击后拦截（攻击后被眩晕则 `afterAttack` 等后续效果全部跳过）。引擎统一拦截，组件无需各自检查。

## 事件总线（V5.3.0）
*   **统一信号**：`on(event, handler, priority)` / `emit(event, data)`，当前信号清单：`beforeSelectTarget`、`beforeAttack`、`beforeDamageCalc`、`beforeDamageCalcFinal`、`beforeDamageApply`、`afterDamageApplied`、`afterAttack`、`afterMiss`、`allyDamaged`、`beforeActionSelect`、`onRoundStart`、`onRoundEnd`、`beforeFirstAllyAttack`。
*   **注册化**：职业（战士破防/远程成长/防战坚盾）、海克斯效果、精英技能全部改为 EventBus 监听器，核心逻辑不再硬编码。每回合 `eventBus.clearAll()` 后重新注册。
*   **统一出口**：所有组件必须导入 `emitCoreEvent`（或 `emitEvent`），禁止直接访问 `window._emitEvent` / `window._battleEvents`。事件通过 `GlobalStore.pushBattleEvent` 入队，播放器统一消费。

## 引擎与 UI 边界
*   **引擎-UI 解耦**：引擎只算账、写战斗日志；播放器读日志控制 Store 更新时机（动画播完才改 hp/pos/alive）。详见 `记录-错误与经验库.md` 四-1。

## 精英组件结构（V5.3.0）
*   **按阵营合并**：`modules/97elite-imperial.js`（成昆/玄冥二老）、`modules/98elite-sixsects.js`（宋青书/周芷若）、`modules/99elite-mingjiao.js`（张无忌/韦一笑/小昭），各暴露 `register(eventBus, A, B, log)`。
*   **23 号文件定位**：无状态的纯工具函数层（`checkKuLian`、`tickXuanmingPoison`、`getXiaoZhaoHexEnhance` 等），被 97/98/99 组件 import 使用，本身不注册任何监听器。

## 精英技能归属原则（V5.3.2）
*   **引擎保留**：通用战场规则——遮挡判定、拒马生成/销毁、属性重置、圣火令行列生成、Buff 统计日志、胜负判定。
*   **组件监听**：特定精英角色的行为逻辑——苦练优先行动、附身/飞天/蛛落、玄冥中毒、快乐回血、性奋授予、九阴白骨爪、玄冥联动、成昆幻影——全部改为监听对应信号，引擎不识别任何具体精英名字。
*   **空列/残血光环**：加成写入 `_emptyColBonus` 和 `_bloodAuraBonus` 字段，由引擎的攻防汇总公式统一计算，不直接改 `atk`，确保详情弹窗可查来源。

## 既有决策
*   **小昭附身**：转移用 `_baseAtk` 防叠加；飞回血量计死亡队友（总血量/总血上限比例）。
*   **妹妹飞天**：百分比只看当前 `maxHp`，别用 `_baseMaxHp`。触发时机用 `beforeDamageApply` 信号。
*   **玄冥联动**：打完必须 `partner._acted = wasActed`，防吞行动。`_isLinkAttack` 标记防递归。
*   **战报修复**：统计字段走 `SYNC_BATTLE_STATS`，引擎侧直接覆写。
*   **圣火令首回合**：`playBattle` 初始 `battleState` 需深拷贝全量 `activeBuffs`。
*   **苦练优先行动**：通过 `beforeActionSelect` 声明 `priority: 1`，行动后不切换阵营。历史教训：V5.3.1 删除 `kuLianUnit` 后曾漏掉阵营切换判断。
