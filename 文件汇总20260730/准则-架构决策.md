# 关键设计决策速查

> 定位：本文档速查"为什么这么设计"的关键决策，每条 1-3 行。
> 详细复盘见 `记录-错误与经验库.md`（四、技术决策档案）；版本变更见 `记录-更改履历.md`。

## 行动裁判（V5.3.1 / V5.3.2）
*   **高优先级行动**：`beforeActionSelect` 声明 `priority`，裁判按 `priority` 降序先动；`isPriorityAction` 标记使行动后不切换 `currentSide`，不占本队正常回合。
*   **三状态**：`priority`（谁先动）/ `skip`（不在战场，小昭姐妹飞天/附身）/ `pass`（存在但无法攻击，行动后不换阵营）。
*   **眩晕双拦截**：`processUnitAttack` 入口拦截（眩晕单位拒收任何攻击指令）+ 攻击后拦截（攻击后被眩晕则本次攻击后续效果全部作废）。

## 事件总线（V5.3.0）
*   **统一信号**：`on(event, handler, priority)` / `emit(event, data)`，9 个攻击生命周期信号（beforeSelectTarget → afterMiss）。
*   **注册化**：职业（战士破防/远程成长/防战坚盾）、海克斯效果、精英技能全部改为 EventBus 监听器，核心逻辑不再硬编码。
*   **统一出口**：所有组件必须导入 `emitCoreEvent`（或 `emitEvent`），禁止直接访问 `window._emitEvent` / `window._battleEvents`。

## 引擎与 UI 边界
*   **引擎-UI 解耦**：引擎只算账、写战斗日志；播放器读日志控制 Store 更新时机（动画播完才改 hp/pos/alive）。详见 `记录-错误与经验库.md` 四-1。

## 精英组件结构（V5.3.0）
*   **按阵营合并**：`modules/97elite-imperial.js`（成昆/玄冥二老）、`modules/98elite-sixsects.js`（宋青书/周芷若）、`modules/99elite-mingjiao.js`（张无忌/韦一笑/小昭），各暴露 `register(eventBus, A, B, log)`。

## 既有决策
*   **小昭附身**：转移用 `_baseAtk` 防叠加；飞回血量计死亡队友。
*   **妹妹飞天**：百分比只看当前 `maxHp`，别用 `_baseMaxHp`。
*   **玄冥联动**：打完必须 `partner._acted = wasActed`，防吞行动。
*   **战报修复**：统计字段走 `SYNC_BATTLE_STATS`，引擎侧直接覆写。
*   **圣火令首回合**：`playBattle` 初始 `battleState` 需深拷贝全量 `activeBuffs`。
