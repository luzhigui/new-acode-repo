## 一、BUG 模式（2026-10-31 已删除）

**是什么**：开发调试入口，作用是让海克斯选卡**不随机抽 3 张**，直接把全部可用 buff 列出来。

**原入口**（`dev-index.html`）：弱精英按钮组与「🏪 圣火令商店」之间，红色渐变按钮。
```html
<button class="big-btn btn-play" id="btnBugMode"
        style="background:linear-gradient(135deg, #ff5252, #b71c1c);">🐛 Bug模式</button>
```

**链路**：
1. 点击 → `localStorage.setItem('_bugMode','1')` + `GlobalStore.set('bugMode', true)` → 跳 `index.html`。
2. 启动注入：`ui/60main-utils.js` `initBugAndXiaoZhaoModes()` 读到 `_bugMode` → `GlobalStore.set('bugMode', true)` → `removeItem`。
3. 生效点：
   - `ui/70buff-dialog.js`（海克斯弹窗）：`if (GlobalStore.get('bugMode')) choices = available; else 洗牌取 CONFIG.BUFF_CHOICES || 3`；
   - `ui/65main-battle.js`（战斗中选卡）：同款三元分支。
4. 默认值：`infra/54-global-store.js` 默认表 `bugMode: false`。

**删除范围**（工作区未提交）：`dev-index.html`（按钮 + 9 处 `removeItem('_bugMode')`）、`ui/60`（分支）、`ui/65`、`ui/70`、`infra/54`（默认键）。

**恢复方法**：删除尚未提交，`git show HEAD:dev-index.html` / `HEAD:ui/70buff-dialog.js` 可取回原文；或按本节三处（入口按钮 / 启动注入 / 选卡分支）重建。
