## 远程命中被攻击者颤动（2026-09-03 定稿）

**定位**：只有远程飞箭命中，被攻击的格子才颤动；近战（飞撞/白骨爪/溅射爪/斩杀）一律不加。

**触发**（仅 `fx/81fx-arrows-5v5-test.js`）：
- 主箭命中：`markGridShake(unitD.uid, 350)`
- 溅射箭命中：`markGridShake(st.uid, 300)`

**实现**（`render/32-grid-render.js`）：渲染层维护 `_shakeUntil`（uid→到期时间戳）；`renderGrid` 每次重建格子时若未到期，对**新格子**播放 `runGridShake` rAF 颤动并续期。

**视觉**：逐帧随机偏移 ±2px（decay 线性衰减）+ `translate+scale` 0.88→1.0 缩放回弹（300~350ms）+ 短暂黄闪（≤200ms，金黄色 #ffd700）；结束后还原原 transform/background。

**关键坑（防再犯）**：
1. **不要直接改格子 DOM 颤动**——store 任意一次 dispatch 都会触发 `renderGrid` 用 `innerHTML=''` 整体重建，直接改 cell.style 会被下一帧 rebuild 掐掉。必须走渲染层 `markGridShake` + 重建续期。
2. **不要用 CSS `.shake` class（±5px 横移）**——远古做法，观感差，已被否定。
3. **不要做 overlay 浮层**（半透明黄块）——观感与格子本体颤动完全不同，已被否定。
4. **粒子函数删干净**：`applyImpactShrink`/`applyImpactShrinkOverlay` 已从 `fx/80fx-common` 删除，全库无残余调用；82 无 markGridShake import。
5. 命中颤动是全屏幕持续战斗内容，**暂停（isPaused）时动画应冻结**——当前 runGridShake 用 Date.now()，若需暂停冻结需改用 rAF 累计模式。

## 白骨爪全套节奏（2026-11-07 定稿，不要乱改）

> **结论：下面这组「白骨爪打人的速度 + 被打者掉血飘字的节奏」是老板实测认可的定稿，不要乱改。**
> 要动必须先跑实测，并明确「改哪个参数、为什么、改完节奏如何」；不得顺手调参、不得全局倍率一把梭。
> 复盘与踩坑记录见 [错误与经验库 · 第十一节 白骨爪节奏定稿](../11%20错题集及履历/01%20错误与经验库.md#十一白骨爪节奏定稿2026-11-07)。

**涉及文件（只有这四处，改一处就会动整体节奏）：**

| 文件 | 位置 | 管什么 |
|---|---|---|
| `fx/602-fx-arrows-5v5-test.js` | `showBoneClaw` | 凝结 → 飞行 → 命中/斩杀 |
| `core/223-perf-params.js` | `clawStart` / `clawSpeed` / `floatLife` | 三个参数表（按倍速档位） |
| `player/509-attack-group.js` | `isClawHit` / `clawFast` 分支 | 爪击日志行与行间停顿 |
| `fx/601-fx-common-5v5-test.js` | `showDamageFloat` | 掉血飘字存活、同单位错位窗口 |

**1) 凝结放大 `clawStart`（ms，key = 倍速值：0.5x / 1x / 2x / 4x / 8x）**

| 倍速 | 0.5x | 1x | 2x | 4x | 8x |
|---|---|---|---|---|---|
| `clawStart` | 200 | 160 | 120 | 96 | 80 |

**2) 飞行速度 `clawSpeed`（px/ms，档位同上）**

| 倍速 | 0.5x | 1x | 2x | 4x | 8x |
|---|---|---|---|---|---|
| `clawSpeed` | 0.65 | 0.98 | 1.30 | 1.95 | 2.60 |

- 飞行时长 = `max(80, 距离 / clawSpeed)` —— 近距离保底 **80ms**。
- **不要**改回 250ms 之类的大保底：会把近战爪速参数完全吃掉（踩过的坑）。

**3) 命中与斩杀**

- 命中后停顿 `pauseAfterHit` = **100ms**（写死在 `showBoneClaw`，不进参数表）。
- 命中反馈：格子抖动 `markGridShake(…, 250)` = **250ms**；黄光 `flashBoneClawHit` = 亮 **180ms** + 淡出 **150ms**。
- 斩杀分支：放大到 2.2 用 **400ms** → 停留 **500ms** → 淡出 **300ms** → **600ms** 时碎开 → **1000ms** 清场；碎开后红闪 **300ms** 才开始 **400ms** 淡出。

**4) 爪击日志（`player/509-attack-group.js`）**

- 爪击行**整行瞬出、不走逐字**（逐字会拖过动画时间）。
- 出完整行后停 **500ms**（`isClawHit`）/ **350ms**（`clawFast` 随爪衍生）。
- 爪击条目之间再停 **60ms**，形成连续快打；同时给目标 `markGridShake(…, 250)`。
- 这三段（瞬出、500/350、60）是「一下一停、读得清」的来源，改任意一段都会让爪击变拖或糊成一片。

**5) 掉血飘字（`fx/601-fx-common-5v5-test.js`）**

- 存活 `floatLife`（ms，档位同上）：**2600 / 1820 / 1300 / 650 / 455**；文案 `💥-N`，右缘锚定。
- 同单位近窗错位：`DMG_STACK_WINDOW = 350ms`、`DMG_STACK_STEP = 30px`、最多 **3 层**。
- 这个 350ms 窗口是刻意收窄后的值：旧版 1200ms 想覆盖 500ms 连击，结果每爪 +30px 越飘越高（已被老板否掉）；现在爪击各自归位，只有同帧主攻 + afterText 连飘才错层。**不要为了「让爪击错开」把窗口调回 1200 级。**

**6) 验收口径**

改完必须肉眼确认「爪打到人 → 停顿可读 → 飘字不叠成一坨、也不越飞越高」，并说明改了哪个参数、各档新值；没有实测拍板不动这一组数。
