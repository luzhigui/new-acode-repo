## 一、8 项硬清单（逐项打勾）

| # | 位置 | 要做什么 | 漏了会怎样 |
|---|---|---|---|
| 1 | `content/001-game-data.json` → `characters` | 条目字段齐全：`named / tags（含职业）/ m / poolTier / flag / tier / camp / sect / enemyOrder / titleOrder`；带 `skills`（name + desc，图鉴/浮层用）、`taunts`、`mechanics`。**若原为普通兵 → 原地升级，不许新增同名键**（重复 key 静默覆盖） | 图鉴空白、台词空、玩家看不到技能说明 |
| 2 | `infra/106-battle-enums.js` | 新机制类型进 `MECHANIC_TYPES`（一个机制一个 key，禁止裸字符串） | content 引用未知类型 → 安装期抛错 |
| 3 | `core/218-state-keys.js` | 每个新 `_xxx` 状态字段登记（类型 + 默认值） | `Unit.clone` 撞 `assertStateFullyRegistered`，带该角色的对局全炸 |
| 4 | `modules/3xx-*.js` + `modules/301-reg-mechanics.js` | 新机制模块落盘，并在 301 **加一行 import**；`registerMechanicHandler` 注册 | 模块不加载 = 机制静默失效，日志里什么都不发生 |
| 5 | 出场通道（二选一，改哪条写哪条） | ① 弱精英随机混入 → `modules/330` 的 `SIX_SECTS_WEAK_ELITE_POOLS`；② 关卡固定 → `content` 的 `ELITE_POOL` 或 `squadVariants`。**动 squadVariants = 改随机流，必须 bump `RNG_CONTRACT_VERSION` 并重录 `tests/rng-draw-baseline.json`** | 角色永远不出现，或冻结种子回放/基线全失配 |
| 6 | `dev-index.html` | 主页加一个强制出场按钮（弱精英走 `_forceWeakElite`；六大派带技能兵走 `_forceSectUnit`；强精英走 `_forceXxx`），并写对应 click 处理 | 出现「只加了一半」：只能手改 localStorage 才能验 |
| 7 | 演出 / 数值可见性 | 伤害或回血**必须** `applyStatChange` + `emitHpChange`（血条） + `pushSkillAnnounce`（日志带前后血量，如 `N → M`）；不吃攻击链的群体伤害尤其容易漏 | 日志有字、格子血条不动（历史高频 bug） |
| 8 | 评测 / 工具链 | 跑一次对应评测确认在册：弱精英 → 工具箱「🐦 弱精英评测」（按 `m` + 有 skills 自动收录，无需改代码）；关卡角色过滤 → 工具箱 820（读同一常量，无需改代码）；跑完存快照供 826 告警 | 数值没人测，强度失衡无告警 |

## 三、历史漏项（照这份清单就不会再犯）

1. `218` 未登记状态字段 → 带该角色的整局崩溃（小昭·姊、空智都踩过）。
2. 机制模块不 import 进 `301` → 技能装了但一次都不触发。
3. 普通兵升级时**新增**同名 key → JSON 重复键，实际生效的是后者，前者静默丢弃。
4. 群体真伤直接改 `hp` 不发 `emitHpChange` → 血条不动（魔化谢逊 28 点真伤踩过）。
5. 死亡广播（`ON_UNIT_DEATH`）里推 `declarations` → 没有任何一方消费，等于零伤害。
6. 永久加成靠 `state._xxxApplied` 防重 → 每回合 install 重跑 + clone 丢标记 → 逐回合叠加（渡厄攻归零踩过）。
7. 加弱精英忘了 `dev-index` 按钮 → 就是 2026-11-28 这次。
8. 动 `squadVariants` 不同步 RNG 契约 → 回放与基线全失配。
