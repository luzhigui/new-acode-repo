## 一、通用教训（11 条）

> 「数据污染」「函数职责单一」两条与 `准则-开发准则.md` 重复，已收口到那边，此处不再重复。

1. **状态隔离**：敌我/双方状态必须独立存储，禁止共享全局计数器。
2. **顺序就是逻辑**：先放数据再判定，数据没就绪不做检测。
3. **治标不如治本**：删东西是最危险的修复，先问"是谁写进来的"。
4. **全局视野**：核心文件反复查不出问题时，立即转查调用方/事件绑定/回调。
5. **模块合并三要素**：顶层变量唯一化、import 用 `[\s\S]*?` 跨行匹配、路径用绝对路径。
6. **模块化重构**：模块只与调度中心单向交互、接口少而简、项目规模决定架构复杂度。
7. **交付自审**：所有导出函数必须有实际实现，禁止注释占位符（`/* ... */` 假装代码）。
8. **排查方向**：从最终调用处（末端）向上追溯，不从中间层开始开改。
9. **故障隔离**：BGM/SFX 独立通道，一个模块加载失败不得通过共享标志位连带禁用另一个。
10. **事件信号全覆盖**：命中/未命中/闪避/死亡每条分支路径都必须发射对应信号。
11. **重试重置状态**：重试/递归调用前重置 `_acted` 等状态标志；同类处理器状态重置逻辑要对齐。

## 二、特效与表现（已进代码，仅索引）

原则：特效走数据标记（`_flash` / `_flyMode` / `_phantomTarget` 等），`renderGrid` 统一读取渲染；禁止特效函数直接操作 DOM。V6.1.0 起进一步禁止缓存 cell DOM 引用（grid 重绘即重建 DOM），cell 获取统一走 `fx/90fx-ref-manager.js` 实时查询/纯坐标快照；fact 内一律纯数据快照，禁塞活体 Unit 对象。

- 公共 / 飞箭 / 飞撞：`fx/80fx-common-5v5-test.js`、`81fx-arrows-5v5-test.js`、`82fx-crash-5v5-test.js`
- 换位 / 击退 / 闪避反击：`fx/83fx-position-swap.js`、`84fx-push-back.js`、`85fx-dodge-bullet.js`
- 小昭飞天 / 附身：`fx/86fx-butterfly-spider.js`
- 统一管理 / 触发：`fx/87fx-manager.js`、`88fx-trigger.js`
- 渲染层：`render/30-fact-renderer.js`、`32-grid-render.js`

两条规范：
- 特效关键参数集中在文件顶部 `PARAMS` 对象，函数内禁止裸数字，便于调参移植。
- 尾焰/光晕等需跟随角色的元素，挂为角色子元素用 CSS 自动跟随，勿逐帧手动同步坐标。

## 四、专项修复复盘

- **反击风暴**：子元素内联 `transform` 会覆盖 CSS 动画 → 把 `rotateX(75deg)` 移到父容器，子元素动画改纯 `rotateZ`。见 `fx/85fx-dodge-bullet.js`。
- **弹幕/飘字消失（对象池）**：对象池元素禁止标记 `data-fx="temporary"`，否则关卡切换 `clearAllEffects` 会把池内元素从 DOM 删除。
- **小昭姐妹 `_flyMode` 丢失**：引擎事件若中途 `return` 跳过正常事件流转，事件会留在队列被后续 `flushBattleEvents()` 清空 → 需在产生点手动 flush + dispatch + updateUI。
- **文件复制器**：弹窗必须显示"当前已复制的包"，先显示再 `sendIndex++` 切下一包。
- **BGM**：走 Web Audio 缓存模式（`fetch` + `decodeAudioData` + `createBufferSource`），与 SFX 同通道；VSCode 预览与手机端均可播放。
- **文件复制器（acode 批量 fetch 断连）**：acode 内置浏览器连续 fetch 本地文件约 60 个后偶发随机断连，只报 `Failed to fetch`（非 404）。特征：失败文件每次不同、随"临界位置"漂移，单独复制必成功；与路径 `../` vs `./`、文件名中文/ASCII 均无关。解法：首轮读完对失败文件统一补读一轮（每文件仅 1 次，非死循环）。见 `tools/103-toolkit.js` `readFileOnce`。

## 五、V5.5.x 补录（2026-08）

1. **额外攻击"声明制"收敛（V5.5.1）**：概率连击/嗜血/性奋/小昭永久连击/玄冥联动全部收敛为 `extraRequests` 声明集合——子级只 push `{ reason, unit, actedMode, priority }`，父级统一排序去重执行；`actedMode:'restore'` 恢复 `actedSnapshot`。教训：跨组件共享的执行流一律"子级声明、父级统一执行"。
2. **infra 小文件合并（V5.5.4）**：51-fsm / 52-rng / 53-battle-event-store / 55-battle-math 合并为 `infra/51-core-utils.js`。教训：文件粒度太碎放大 import 链路，同类无状态小工具收敛到一个文件。
3. **依赖方向收口（V5.5.4）**：`calcDamage` 等公共工具下沉 infra，断开 `render → core` 反向依赖；`_triggerFX` 下沉到 `fx/88fx-trigger.js`，断开 `player → ui`。教训：目录层级代表依赖方向，渲染层/播放器不应反向依赖核心层。
4. **window 全局变量收口（V5.5.4）**：B 类桥改走 `GlobalStore.setUIHandler`，C 类死引用删除；修复 4 个 fx 文件读 `window._fastForwardActive` 但从未赋值的静默失效。教训：全局桥必须统一出口，散落 window 读写是"读了没赋值"类静默 bug 的温床。
5. **0.1 精度与显示取整（V5.5.3）**：计算统一 0.1 步长；攻防显示取整、格子比较基准取整。教训：计算步长与显示取整分层，别让浮点误差漏到界面。

## 六、V6.1.0 补录（2026-09）

1. **cell DOM 引用缓存（fx 通病）**：grid 每次重绘重建 DOM，特效缓存的 cell 引用变游离元素 → 克隆体极小、残留蓝格子、动画掐断。解法：`fx/90fx-ref-manager.js` 统一实时查询/纯坐标快照，永不缓存 cell DOM。
2. **rAF 递归用旧时间戳**：82fx `phaseReturn` 递归复用闭包旧时间戳，暂停后进度不推进、灰格卡在半路。教训：递归动画循环每次迭代必须重新取 `performance.now()`。
3. **特效误清他人状态**：82fx 开头误清 `CLEAR_UNIT_FLASH`，蓝色闪示只闪一下。教训：状态清理权归状态写入方（handleAttackGroup），特效只消费不清理。
4. **重构夹带私货**：82fx 重写时新增了原代码没有的近战颤动（另恢复 `data-flash` 后克隆体发灰同源）。教训：重构只做等价迁移，不得夹带新行为；样式表现交 CSS 属性驱动（`data-flash="attack"`），勿手动搬样式。
5. **弹幕时序（afterText vs beforeText）**：ATK_BUFF 挂 afterText，等整行文本念完才飘，感知"慢"。解法：改 beforeText + 延迟 200ms，翻译器 heal 排前。教训：加攻/回血类即时反馈挂 beforeText。
6. **状态标志漏清**：小昭·姊 `_executeReturn` 正常分支漏清 `_flyMode`，飞回后格子不恢复。教训：状态标志的设置/清理必须成对出现在同一函数的所有分支。
7. **积分保护顺序错误**：原代码先写 localStorage 再读旧值比较，保护形同虚设；拆分时还被遗漏。教训：阈值保护必须"先读旧值 → 判保护 → 再写入"（`shouldPersist` 由调用方落盘）。
8. **随机被历史短路**：BGM init 优先读历史选择，每次启动同一首。教训：随机入口不得被持久化历史覆盖。
9. **状态变化信号散落（架构级）**：死亡/换位/飞天等变化有的只发 eventBus、有的只 push fact、有的什么都不发 → 张无忌/成昆等依赖方漏触发，靠回合开始兜底补查。解法：唯一发射口 `emitStateChange`（infra/59）+ 裁判 `watchUnit`（core/19）；回合 `clearAll()` 后必须 `clearAllWatchers()`。

## 七、V7.3–V7.4 补录（2026-09 中下旬）

> V6.3–V7.2 的教训直接见 `记录-更改履历.md` 对应条目（含渲染层拆分三批次 V7.0.0–V7.0.2），此处只收高频踩坑结论。

1. **面板与现算同源（V7.4.2）**：闪避面板读词条化时已剥离的 `unit.buffDodgeBonus`（全库无写入源）→「流云身法」永不显示。教训：面板展示一律与数值现算同源（`computeBuffStats`），不读死字段。
2. **渲染层不持引擎 FSM（V7.3.0/V7.4.3）**：`render/32` 读 `unit._fsm.is(...)` 一处耦合倒逼出 3 处序列化 shim；解法是 FSM 相位镜像 `_fsmPhase` 随 state schema 三线全通，shim 全删。教训：渲染层要读的相位走 state 镜像字段；纯渲染态字段收进 `infra/61-view-sheet.js` 视图表——units 只装账本。
3. **死亡一律统一结算（V7.4.5）**：闪避反击直接 `alive=false` → 带血尸体 + 死亡信号不发（`watchUnit`/替死失效）；0.8 血被 `Math.floor` 成 0 造成假死。教训：致死只挂 `_pendingDeath` 交 `resolveDeaths`，血量存真实值不取整。
4. **通用钩子不得凌驾角色级声明（V7.4.5）**：`core/11` 通用飞行选敌钩子盖过角色声明，母狮成固定靶。教训：通用规则只兜底，角色级声明优先（已删钩子回归 `core/07` 策略表）。
5. **配置=基础值口径（V7.4.6）**：三狮数值当最终值写进配置，`spawnUnit` 的 `applyBonus` 被后续 `stats` 覆盖静默吞掉。教训：配置 `atk/def/maxHp` 一律基础值、职业加成由引擎叠；个别豁免走 `skipRoleBonus` 显式声明。
6. **特效 emit 在出手帧，不在生成步（V7.4.7）**：modules 生成步画面还没播，直接 emit 会抢跑。定式：生成步只写 fact 标记 → `render/38` 搬运 → `render/39` 出手帧 emit `FX_SIGNALS` → fx 订阅。demo 接入三硬约束：等待/动画走 clock、cell 走 `getUnitCell` 实时查、朝向按阵营行序判不写死。
7. **`.gitignore` 只管未跟踪文件（V7.4.8）**：把忽略行加回去不会让已入库文件退出仓库；真回收要 `git rm -r --cached`，而该提交被别的机器 pull 会连带删掉其本地副本——回收前先把目录备份到仓库外。
