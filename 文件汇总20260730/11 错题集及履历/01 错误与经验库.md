## 一、通用教训（12 条）

> 「数据污染」「函数职责单一」两条与原 `准则-开发准则.md`（已删除）重复，已收口到 `12 协议与准则/01 工程决策.md` 与核心工作准则，此处不再重复。

1. **状态隔离**：敌我 / 双方状态必须独立存储，禁止共享全局计数器。
2. **顺序就是逻辑**：先放数据再判定，数据没就绪不做检测。
3. **治标不如治本**：删东西是最危险的修复，先问“是谁写进来的”。
4. **全局视野**：核心文件反复查不出问题时，立即转查调用方 / 事件绑定 / 回调。
5. **模块合并三要素**：顶层变量唯一化、import 用 `[\s\S]*?` 跨行匹配、路径用绝对路径。
6. **模块化重构**：模块只与调度中心单向交互、接口少而简、项目规模决定架构复杂度。
7. **交付自审**：所有导出函数必须有实际实现，禁止注释占位符假装代码。
8. **排查方向**：从最终调用处（末端）向上追溯，不从中间层开始开改。
9. **故障隔离**：BGM / SFX 独立通道，一个模块加载失败不得通过共享标志位连带禁用另一个。
10. **事件信号全覆盖**：命中 / 未命中 / 闪避 / 死亡每条分支路径都必须发射对应信号。
11. **重试重置状态**：重试 / 递归调用前重置 `_acted` 等状态标志；同类处理器状态重置逻辑要对齐。
12. **文档 ≠ 实现**：文档里的「机制设想」未必有结算——如「四职业克制环」代码里无对应结算（2026-09-28 核对），引用「机制」前先读代码。

## 四、专项修复复盘

> 现象 → 根因 → 教训，逐条压成一句；完整过程见根目录 `记录-更改履历.md`。

- **反击风暴**：子元素内联 `transform` 覆盖 CSS 动画 → 母容器的 `rotateX(75deg)` 与子元素 `rotateZ` 分层（`fx/85fx-dodge-bullet.js`）。
- **弹幕 / 飘字消失**：对象池元素被标 `data-fx="temporary"` → 关卡切换 `clearAllEffects` 连池内元素一起删 → 池元素禁止该标记。
- **小昭姐妹 `_flyMode` 丢失**：引擎事件中途 `return` 跳过流转，事件留队列被后续 `flushBattleEvents()` 清空 → 产生点手动 flush + dispatch + updateUI。
- **文件复制器**：弹窗须先显示“当前已复制的包”再 `sendIndex++`；acode 内置浏览器连续 fetch 约 60 个后偶发断连（失败文件每次不同）→ 失败文件统一补读一轮（`tools/803-toolkit.js` `readFileOnce`）。

## 五、V5.5.x 补录（2026-08）

> 五条教训：①跨组件共享执行流一律「子级声明、父级统一执行」（`extraRequests`）；②同类无状态小工具收敛到一个文件（文件太碎放大 import 链路）；③目录层级＝依赖方向，render / player 不得反向依赖 core / ui；④全局桥统一出口（散落 window 读写会出“读了没赋值”的静默 bug）；⑤计算步长与显示取整分层。详见根目录 `记录-更改履历.md` V5.5.x。

## 六、V6.1.0 补录（2026-09）

> 四条最贵：①cell DOM 缓存必失效（grid 重绘重建 → 克隆体极小 / 残蓝格），统一走 `fx/90` 实时查询；②状态清理权归写入方，特效只消费；③重构只做等价迁移，不得夹带新行为；④状态变化唯一发射口 `emitStateChange` + 裁判 `watchUnit`，回合 `clearAll()` 后必须 `clearAllWatchers()`。其余（rAF 旧时间戳、弹幕 beforeText、状态标志成对清理、积分保护先读后写、随机不被历史覆盖）见履历 V6.1.0。

## 七、V7.3–V7.4 补录（2026-09 中下旬）

> 七条：①面板展示与现算同源（不读死字段）；②渲染层读相位走 state 镜像 `_fsmPhase`，不读引擎 FSM；③致死统一挂 `_pendingDeath` 交 `resolveDeaths`，血量存真实值不取整；④通用钩子不得凌驾角色级声明；⑤配置 `atk/def/maxHp` 一律基础值，职业加成由引擎叠；⑥特效 emit 在出手帧而非生成步；⑦`.gitignore` 只管未跟踪文件。详见履历 V7.3–V7.4。

## 八、工具链补录（2026-09 下旬）

> 实验设计教训：随机阵容 / 无海克斯 / 局数少 → 噪声盖过参数效果，须固定单关 + 固定 N 套阵容 + 同一 `(阵容, 局序)` 同一 seed 跑基线与补丁两臂。另：小 seed 先散列（`mixSeed`）；造海克斯别用 `createBuffObject`（会动战斗随机序列）；参数分 `mechanics.*` 与 `skills.*.params.*` 两处、是否生效以跑出来为准；内嵌 webview 用页内 mask + 同源 iframe；旋钮标签必须显中文。见 `tools/120-param-lab-core.js`。

## 九、音频通道排查补录（2026-11-05）

> 现象：BGM 改 `<audio>` 后全哑、四次改道才查到根因。根因：`sw.js` 的 `Response.error()` + `play()` 的 `.catch(() => {})` 静默吞错，且排查跳过“先取证通道”。教训：①先取 `location.protocol` 与 `currentBgmId`（有值 ≠ 起播成功）再查解码；②播放失败必须留日志；③取证只用公开字段（`queryObjects` / `$0` 在 IIFE 里不存在）；④file:// 下 `transferSize = 0` 正常，以 `decodeAudioData` 成功与时长为准；⑤「禁兜底」允许改判据、不允许加双通道自动回退。`d65824b1` 起 file:// 也走 WebAudio。

## 十、接管型特效与锚点取值补录（2026-11-06）

> 现象：唐文亮「冲刺·七伤齐发」只演一部分。根因：接管者内部的静默 `return` 前置条件与外部跳过默认演出互不兜底。教训：①接管者只在 payload 结构性缺失时才退出，其余一律真格兜底继续演；②锚点按 uid 找（排除法会静默抓到队友）；③取值前先判 `position` 口径（fixed vs relative）。

## 十一、白骨爪节奏定稿（2026-11-07）

> **这一组「白骨爪打人速度 + 掉血飘字节奏」是老板实测认可的定稿，别乱改**；参数表见 `100 资产要保留找机会梳理/04 补充-特效规范.md`「白骨爪全套节奏（2026-11-07 定稿·不要乱改）」。现象：两次调参被否（飞行保底 250ms 吃掉近战爪速；飘字错位窗口 1200ms 让每爪越飘越高）→ 根因：保底值与错位窗口跨量级 → 教训：保底 80ms、窗口 350ms / 30px / 最多 3 层，改动前先跑实测并说明改哪个参数，不许全局倍率一把梭。
