## 一、通用教训（12 条）

> 「数据污染」「函数职责单一」两条与本库重复，已收口到 `12 协议与准则/01 工程决策.md` 与核心工作准则。

1. **状态隔离**：敌我 / 双方状态必须独立存储，禁止共享全局计数器。
2. **顺序就是逻辑**：先放数据再判定，数据没就绪不做检测。
3. **治标不如治本**：删东西是最危险的修复，先问“是谁写进来的”。
4. **全局视野**：核心文件反复查不出问题时，立即转查调用方 / 事件绑定 / 回调。
5. **模块合并三要素**：顶层变量唯一化、import 用 `[\s\S]*?` 跨行匹配、路径用绝对路径。
6. **模块化重构**：模块只与调度中心单向交互、接口少而简、项目规模决定架构复杂度。
7. **交付自审**：所有导出函数必须有实际实现，禁止注释占位符假装代码。
8. **排查方向**：从最终调用处（末端）向上追溯，不从中间层开始开改。
9. **故障隔离**：BGM / SFX 独立通道，一个模块加载失败不得通过共享标志位连带禁用另一个。
10. **事件信号全覆盖**：命中 / 未命中 / 闪避 / 死亡每条分支路径都必须发射对应信号。
11. **重试重置状态**：重试 / 递归调用前重置 `_acted` 等状态标志；同类处理器状态重置逻辑要对齐。
12. **文档 ≠ 实现**：文档里的「机制设想」未必有结算——如「四职业克制环」代码里无对应结算（2026-09-28 核对），引用「机制」前先读代码。

## 三、专项修复复盘（一句一条，过程见履历）

- **反击风暴**：子元素内联 `transform` 覆盖 CSS 动画 → 母容器与子元素分层（`fx/606-fx-dodge-bullet.js`）。
- **弹幕 / 飘字消失**：对象池元素被标 `data-fx="temporary"`，关卡切换 `clearAllEffects` 连池内元素一起删 → 池元素禁止该标记。
- **小昭姐妹 `_flyMode` 丢失**：引擎事件中途 `return` 跳过流转，事件留队列被后续 `flushBattleEvents()` 清空 → 产生点手动 flush + dispatch + updateUI。
- **文件复制器**：弹窗须先显示“当前已复制的包”再 `sendIndex++`；acode 内置浏览器连续 fetch 约 60 个后偶发断连 → 失败文件统一补读一轮（`tools/803-toolkit.js` `readFileOnce`）。

- **V5.5.x（2026-08）**：跨组件共享执行流一律「子级声明、父级统一执行」；同类无状态小工具收敛到一个文件（碎文件放大 import 链路）；全局桥统一出口；计算步长与显示取整分层 → 详见履历 V5.5.x。
- **V6.1.0（2026-09）**：cell DOM 缓存必失效（grid 重绘重建），统一实时查询 `fx/611`；状态清理权归写入方，特效只消费；重构只做等价迁移、不夹带新行为；状态变化唯一发射口 `emitStateChange` + 每回合 `clearAllWatchers()` → 详见履历 V6.1.0。
- **V7.3–V7.4（2026-09 中下旬）**：面板展示与现算同源（不读死字段）；渲染层读相位走 state 镜像 `_fsmPhase`；致死统一挂 `_pendingDeath` 交 `resolveDeaths`，血量存真实值不取整；配置 `atk/def/maxHp` 一律基础值；特效 emit 在出手帧而非生成步；`.gitignore` 只管未跟踪文件 → 详见履历 V7.3–V7.4。
- **工具链（2026-09 下旬）**：随机阵容 / 局数少会让噪声盖过参数效果 → 固定单关 + 固定 N 套阵容 + 同一 `(阵容, 局序)` 同一 seed 跑两臂；小 seed 先 `mixSeed`；造海克斯别用 `createBuffObject`（会动战斗随机序列）；参数分 `mechanics.*` 与 `skills.*.params.*` 两处，是否生效以跑出来为准 → 见 `tools/822-param-lab-core.js`。
- **音频通道（2026-11-05）**：`sw.js` 的 `Response.error()` + `play().catch(()=>{})` 静默吞错导致全哑 → 排查先取证（`location.protocol` / `currentBgmId`，有值 ≠ 起播成功），播放失败必须留日志；「禁兜底」允许改判据、不允许加双通道自动回退。
- **接管型特效（2026-11-06）**：接管者内部的静默 `return` 前置条件与外部跳过默认演出互不兜底 → 只在 payload 结构性缺失时才退出，其余真格兜底继续演；锚点按 uid 找，取值前先判 `position` 口径（fixed vs relative）。
- **白骨爪节奏（2026-11-07 定稿·别乱改）**：两次调参被否（飞行保底 250ms 吃掉近战爪速；飘字错位窗口 1200ms 让每爪越飘越高）→ 保底 80ms、窗口 350ms / 30px / 最多 3 层；改动前先跑实测并说明改哪个参数，不许全局倍率一把梭 → 参数表见 `100 资产要保留找机会梳理/04 补充-特效规范.md`。
