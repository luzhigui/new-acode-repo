## 二、终态目标（高考终局）

一套"**变更探测器**"——对游戏的**任何改动**，能自动回答"什么行为变了、是回归还是预期"，且**自身可证无假绿**：

1. **数值真值网 100% 覆盖**：每个真正改 `atk/def/maxHp` 的 `_mods` group 都有契约（零主代码，账本模式兜底）。
2. **fact 类型全覆盖**：`infra/58` 每个注册 fact 类型都有渲染器 + 消费方；无孤儿登记、无"无渲染 fact"。
3. **规则牙齿化**：每条核心规则都有变异牙齿，证明它"非恒绿"（目前仅 8/43 条有牙齿）。
4. **不变量网**：`hp∈[0,maxHp]` / 血条==引擎值 / `pos` 唯一 / 关键状态（buff 面板 / 闪避 / 附身窗口）逐步断言。
5. **工具自证固化**：每轮自动跑 `--scan-groups` + `--fingerprint` 对照，新机制 / 新 group 自动报警，不必人肉排查。

## 三、分阶段路线（3 年规划 · 5 年高考）

### 阶段一 · 数值真值网闭环（当前轮启动）
- **方法**：周期性跑 `node tests/stat-decl-vs-actual-check.mjs --scan-groups`，把真实出现却未绑契约的 `_mods` group 全枚举出来，逐条补契约。
- **本轮目标 `soulDrain`（摄魂）**：`--scan-groups` 命中——827 条 `atk` 词条、零契约。
  - 根因：它是 `core/04` 用 `addMod(op:'mul', group:'soulDrain')` 施加的削弱型海克斯，**不发射数值声明 fact**（不像 HOLY_FLAME 有 `HOLY_FLAME_APPLY`）。
  - 处置：主代码侧补发 `SOUL_DRAIN_APPLY` fact（带 `ratio = CONFIG.BUFFS.soulDrain.atkBonus`，镜像 HOLY_FLAME_APPLY）；体检侧加一条 `mul:true` 契约（同 HOLY_FLAME）。详见下轮需求清单。
- 后续：每次游戏新增数值机制，重跑 `--scan-groups` 即知有无新盲区，闭环补契约为常态动作。

### 阶段二 · fact 类型全覆盖
- 审计 `infra/58-fact-contract.js` 的注册 fact 类型 vs 实际 `emit` 点 + `render/33` 渲染器注册。
- 消除：孤儿登记（历史上 `meteorSplashGrowth` 已修）、无渲染 fact、消费端未适配。
- 每条规则对应的 fact 链路（emit → contract → render → 规则消费）逐条对齐。

### 阶段三 · 规则牙齿化
- 给尚未有牙齿的 35 条核心规则逐一配变异牙齿（目前仅 `125/130/132/138/143/151/159` 等 8 条有）。
- 优先高影响数值回归规则；牙齿走"污染事实写入代码 / 渲染代码"，不碰配置（绕开单源陷阱）。

### 阶段四 · 不变量网扩展 + 工具自证固化
- 补 `buff 面板一致性` / `闪避` / `附身窗口` 等逐步不变量。
- 把 `--scan-groups` + `--fingerprint` 对照接进 `tests/run-all.mjs` 常驻；新机制 / 新 group 自动报警，体检不再依赖人肉发现盲区。
