## 2. 预处理做了什么

- **去字幕**：原图顶/底有标题文字条，用同位置背景渐变色**涂抹覆盖**，不裁切——避免 v1 把冠饰一起切掉。
- **统一画布**：全部重绘到 768×1024，人物占画面高度 ~86%，8 张头顶线 6.2–7.0%、脚底线 90–95%，比例一致。
- **纯几何处理、无 AI 修复**：没有用 AI 补绘/重绘，保证脸和手是原始像素，不引入漂移。

## 3. 上传混元 3.1 的建议

1. 进 `3d.hunyuan.tencent.com` → 多视图（8 图）模式。
2. 在 UI 里把每张拖到**角度相符的槽位**：正面拖前、侧面拖左/右、背面拖后、06 拖左后 3/4。
3. 若 UI 只要求"传 8 张不区分角度"，直接按 01→08 顺序全选即可。
4. 免费额度 20 次/天，出 GLB/OBJ/FBX，带 PBR+自动骨骼。

## 4. 预期管理（重要）

- 多视图输入**主要提升各角度一致性**（不会再出现左右脸对不上的漂移），但**不会**达到像素级保真。
- 混元 3.1 对脸/手部仍有轻度"磨平/塑料感"倾向——这是 3D 重建的固有降解，不是预处理问题。
- 免费版条款：个人非商用；输入不得为真人肖像或受版权动漫 IP。
